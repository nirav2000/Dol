How faithful are these previews? Each card loads the original animation CSS captured from the labelled Git commit, using the original class names, star coordinates and timings where present. The static factor-card markup is rebuilt in an isolated frame; these are source-faithful animation reconstructions, not complete historical app sessions. Historic revisions with no special celebration are displayed as such. Old app scripts, accounts and saved progress are never loaded.

The archive is rebuilt from every reachable Git commit during deployment. If a version introduced no animation change, it intentionally reuses its existing effect. The original seven experimental Prime Lab designs are preserved and selectable on their historical versions.
