# Dol Shared Diagnostics

Version 2.6.0 uses Shared Diagnostics 1.0.0 from `nirav2000/Apps/diagnostics/releases/1.0.0`. Settings > Help improve Dol > Open diagnostics. Capture is OFF until the user consents. It collects approved geometry and received events, not typed answers, account data, or system pixels. Reports stay local until exported or approved for an issue. Owner sign-in and issue creation reuse Apps' existing backend, without adding a token to Dol. The GitHub issue is created in Apps and identifies Dol as the target repository.

Phone, tablet, and desktop Pair Board CSS are separate and scoped by `data-dol-profile`. The maths engine is shared. Verify all viewports, both palettes, target 840, and Enter/Next action placement. Real iOS Safari requires manual testing because WebKit emulation does not prove system keyboard behavior.
